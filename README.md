# Veritas — Loja Virtual de Moda

## 📖 Sobre o Projeto

O **Veritas** é um projeto de desenvolvimento web criado para a disciplina de **Autoria Web**, com o objetivo de aplicar na prática os conhecimentos adquiridos durante as aulas sobre estruturação e estilização de páginas web.

A proposta do projeto consiste na criação de uma loja virtual moderna e visualmente agradável, focada na apresentação de coleções de roupas e produtos de moda. Todo o desenvolvimento foi realizado utilizando apenas **HTML5** e **CSS3**, sem a utilização de JavaScript, priorizando a construção de layouts organizados, responsivos e com boa experiência visual para o usuário.

O projeto também busca reforçar conceitos importantes do desenvolvimento front-end, como:

* Organização de arquivos e pastas;
* Estrutura semântica em HTML;
* Estilização com CSS;
* Uso de Flexbox;
* Responsividade;
* Boas práticas de desenvolvimento;
* Design moderno e minimalista.

---

# 🎯 Objetivo

O principal objetivo do projeto é demonstrar a capacidade de desenvolver uma interface web funcional e estilizada utilizando apenas tecnologias básicas do front-end, fortalecendo o aprendizado dos alunos na área de desenvolvimento web.

Além disso, o sistema foi pensado para simular uma loja virtual real, contendo seções como:

* Banner principal;
* Coleções em destaque;
* Produtos;
* Navegação;
* Rodapé;
* Organização visual moderna.

---

# 🛠️ Tecnologias Utilizadas

As seguintes tecnologias foram utilizadas no desenvolvimento do projeto:

* **HTML5**
